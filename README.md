# three-minutes-slow

Entry for make.fun's [“Make the AI judge feel awe”](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty: a program that writes one short text to `/output/entry.txt`, a text written to relax the AI judge reading it.

The text:

> The square clock has been three minutes slow since 1904. Nobody mends it. The town learned to arrive early, forgot it had learned anything, and the bell still rings on that old, generous time. By evening the square is empty; the clock keeps its own counsel, patient, never right.

## Run it

```sh
node main.ts        # writes /output/entry.txt
```

No network, no dependencies, Node 22 or newer.
